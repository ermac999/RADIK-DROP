# RADIK DROP

Симулятор открытия кейсов в стиле CS2. Развлекательный проект: виртуальные токены, без реальных денег, пополнений, вывода и призов.

## Что есть на сайте

- **Кейсы.** 13 кейсов в трёх разделах. Три легендарных кейса по 200 токенов (Radioactive Burger, Cyber Psycho, Aramzamzam) содержат только Restricted и выше: Dragon Lore, Howl, Gold Arabesque, Gamma Doppler, Printstream и другие. На странице кейса видны содержимое и шансы каждой редкости. Лента прокручивается и плавно останавливается на выпавшем скине. Можно открыть сразу от 1 до 6 кейсов: тогда крутится столько же лент (число задаётся в `ui.maxOpen`).
- **Апгрейд.** Ставите до 6 своих предметов ради более ценного. Шанс считается как «ценность ваших предметов ÷ ценность цели», не больше 90 %, и показывается до запуска.
- **Контракты.** 10 предметов одной редкости меняются на 1 предмет следующей редкости из тех же кейсов. 5 Covert меняются на нож или перчатки.
- **Батл с ботом.** Вы и бот открываете одинаковые кейсы. У кого общая ценность выше, тот забирает все предметы.
- **Продажа.** Выбитые предметы можно продать за токены: сразу из окна дропа, из карточки предмета или все разом в инвентаре. Цена продажи — ценность предмета × `economy.sellRate` (сейчас 0,9).
- **Инвентарь и статистика.** Фильтр по редкости, сортировка, самый редкий дроп, счётчики кейсов, токенов, апгрейдов, контрактов и батлов.
- **Промокоды.** Коды на токены и коды на временный буст шансов.
- **Токены.** Начисляются, пока сайт открыт на экране: 1 токен в 30 секунд, до 100 в день.

Между открытиями обязательна пауза 2,5 секунды. Звуков, мигания и таймеров «успей» нет. Если в системе включено уменьшение движения, анимации отключаются и результат показывается сразу.

## Как запустить

Откройте `index.html` в браузере. Сервер и сборка не нужны.

## Как выложить на GitHub Pages

1. Откройте репозиторий на GitHub → **Settings** → **Pages**.
2. В **Source** выберите **Deploy from a branch**.
3. Выберите ветку с сайтом и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

На бесплатном аккаунте GitHub Pages работает только для публичных репозиториев.

## Как менять настройки

Все настройки лежат в файле **`js/config.js`**. Поменяли значение, сохранили, обновили страницу.

| Что поменять | Где в `CONFIG` |
| --- | --- |
| Стартовый баланс, скорость начисления, дневной лимит | `tokens` |
| Название, цена, раздел и цвет кейса | `cases` |
| Шансы редкостей | `odds` (или `odds` у отдельного кейса) |
| Бонус новичка (первые открытия с повышенными шансами, на сайте не показывается) | `beginnerBonus` |
| Промокоды | `promoCodes` |
| Цвета и ценность редкостей | `rarities` |
| Шанс StatTrak™, ценность предметов и цена продажи | `economy` |
| Апгрейд, контракты, батл | `upgrade`, `contract`, `battle` |
| Длительность анимаций и паузы | `ui` |
| Список скинов | `skins` |

### Скины

Каждый скин — одна строка в `CONFIG.skins`:

```js
{ id: 'ak-47-redline', name: 'AK-47 | Redline', rarity: 'classified', case: 'ak47', image: 'img/skins/ak-47-redline.webp' },
```

- Чтобы **заменить картинку**, положите свой файл в `img/skins/` и поменяйте путь в `image`.
- Чтобы **добавить скин**, допишите строку с новым `id`. Редкости: `consumer`, `industrial`, `milspec`, `restricted`, `classified`, `covert`, `gold`.
- `id` уже существующего скина лучше не менять: по нему предметы хранятся в инвентаре.

### Картинки кейсов

Пока у кейса пустое поле `image`, рисуется временный ящик в цвете кейса со скином-обложкой (`cover`). Своя картинка должна быть квадратной: положите её в `img/cases/` и пропишите путь, например `image: 'img/cases/ak47.webp'`. Так уже сделано у трёх легендарных кейсов. Разделу с такими кейсами можно поставить `featured: true`, тогда карточки будут крупнее.

### Промокоды

```js
{ code: 'START50', type: 'tokens', amount: 50 },                      // +50 токенов, один раз
{ hash: '…', type: 'boost', minutes: 30, odds: { … }, once: false }, // буст шансов на 30 минут
```

Код можно написать открыто (`code`) или спрятать в виде хэша (`hash`), чтобы его не нашли в файле. Чтобы получить хэш для своего кода, откройте сайт, нажмите **F12 → Console** и введите `RADIK.hash('ВАШКОД')`. Регистр и пробелы в коде не важны.

Отдельного значка буста на сайте нет. Пока код действует, на странице каждого кейса показываются настоящие, повышенные шансы. Буст-код с `once: false` можно вводить сколько угодно раз.

## Где хранится прогресс

В `localStorage` браузера. У каждого браузера и устройства свой инвентарь и баланс. Если хранилище недоступно (например, в приватном режиме некоторых браузеров), сайт работает, но прогресс пропадает после закрытия вкладки. Сбросить прогресс можно внизу страницы «Инвентарь».
